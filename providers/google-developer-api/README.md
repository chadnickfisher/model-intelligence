## Privacy data use

- Unpaid Gemini API content may improve products and undergo human review. Paid-service content is not used to improve products, but limited abuse/legal logging applies. EEA/Switzerland/UK receive paid data terms for unpaid services.
- Search and Maps grounding retain relevant prompts and outputs for 30 days. These Developer API rules do not establish Vertex or consumer-product data handling.
